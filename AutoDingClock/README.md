# 钉钉自动打卡 APP

一个 Android 平台的钉钉自动上下班打卡工具，通过无障碍服务模拟手动点击操作。

## ✨ 功能特性

- **定时自动打卡**：设置上下班时间，到时间自动执行打卡
- **模拟点击**：通过 Android 无障碍服务模拟真实手指点击
- **工作日设置**：自定义每周哪几天需要打卡
- **提前/延后**：支持上班提前、下班延后打卡
- **前台服务**：保持后台运行，防止被系统回收
- **开机自启**：设备重启后自动恢复定时任务

## 📱 使用方法

### 1. 安装 APP

```bash
# 使用 Android Studio 打开项目，点击 Run 按钮直接安装
# 或命令行编译：
./gradlew assembleDebug
# APK 输出位置：app/build/outputs/apk/debug/app-debug.apk
```

### 2. 开启权限

首次打开 APP 后，需要开启以下权限：

1. **无障碍服务权限**（必须）
   - 点击"去开启"按钮
   - 在系统设置中找到"钉钉自动打卡"
   - 开启无障碍服务开关

2. **通知权限**（推荐）
   - 允许通知以接收打卡提醒

3. **电池优化白名单**（推荐）
   - 将 APP 添加到电池优化白名单，防止后台被杀

### 3. 设置打卡时间

1. 开启"上班打卡"开关
2. 设置上班时间（如 09:00）
3. 可选择提前几分钟打卡
4. 开启"下班打卡"开关
5. 设置下班时间（如 18:00）
6. 可选择延后几分钟打卡

### 4. 选择工作日

- 点击星期按钮选择需要打卡的日子
- 或点击"设为工作日"一键选择周一至周五

### 5. 测试打卡

- 点击"立即测试打卡"按钮，验证是否能正常打卡
- 测试成功后可放心等待自动打卡

## ⚠️ 注意事项

1. **保持钉钉登录状态**：APP 需要钉钉已登录才能正常打卡
2. **保持网络畅通**：打卡需要网络连接
3. **允许后台运行**：在系统设置中允许 APP 后台运行
4. **关闭省电模式**：省电模式可能限制后台任务
5. **钉钉版本兼容**：不同版本的钉钉界面可能不同，如无法打卡请反馈

## 🔧 技术实现

| 模块 | 技术 |
|------|------|
| 定时调度 | AlarmManager (精确闹钟) |
| 模拟点击 | AccessibilityService |
| 后台保活 | ForegroundService |
| 持久化 | SharedPreferences |
| UI | XML Layout + ViewBinding |

## 📋 权限说明

| 权限 | 用途 |
|------|------|
| BIND_ACCESSIBILITY_SERVICE | 模拟点击操作（核心功能） |
| FOREGROUND_SERVICE | 后台持续运行 |
| POST_NOTIFICATIONS | 打卡提醒通知 |
| SCHEDULE_EXACT_ALARM | 精确闹钟 |
| RECEIVE_BOOT_COMPLETED | 开机恢复定时 |
| REQUEST_IGNORE_BATTERY_OPTIMIZATIONS | 后台保活 |
